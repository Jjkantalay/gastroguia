# Гастрогид на C

Веб-сервер на чистом C без внешних библиотек. Отдаёт сайт в фирменном стиле gastroguia.ru на 20 языках, JSON-API, картинки и переадресует старые адреса WordPress.

## Запуск

Из корня проекта (там, где лежат `content/` и `public/`):

```
c\bin\gastroguia.exe    # Windows: готовая сборка лежит в репозитории
./gastroguia            # Linux/macOS, после sh c/build.sh
```

`c/bin/gastroguia.exe` пересобирается из `c/src` командой `sh c/build.sh` (нужен MinGW) или `c\build.bat` на Windows.

Сайт откроется на http://localhost:8080. Перед первым запуском скачайте фото и фирменную графику: `npm run images:download`.

Параметры:

| Ключ | По умолчанию | Что задаёт |
|---|---|---|
| `-p` | `8080` | порт |
| `-H` | `127.0.0.1` | адрес; `0.0.0.0` — доступ из сети |
| `-c` | `content` | папка с `dishes.json`, `dishes-extra.json` и `i18n.json` |
| `-r` | `public` | картинки и шрифты (`/wp-content/uploads/...`) |
| `-s` | `c/static` | стили и скрипт (`/static/...`) |

## Сборка

- Windows: `c\build.bat` (нужен gcc из [w64devkit](https://github.com/skeeto/w64devkit) или [WinLibs](https://winlibs.com))
- Linux/macOS: `sh c/build.sh`

## Адреса

| Адрес | Что отдаёт |
|---|---|
| `/` | главная: лента кухонь, поиск, разделы по кухням |
| `/dishes?q=тыква&cuisine=armyanskaya&course=выпечка&x=gluten&x=nuts` | каталог с фильтрами; `x` — исключить аллерген |
| `/dishes/plov` | страница блюда |
| `/photos` | миниатюры, авторы и лицензии фото; «?» — найдено простым поиском, стоит проверить |
| `?lang=en`, `?lang=ka`, … | любая страница на одном из 20 языков |
| `/api/dishes`, `/api/dishes/plov` | JSON |
| `/bliuda/...`, `/kukhnia/...`, `/hingalsh/` | 301 на новые адреса |

## Языки и данные

- `content/i18n.json` — 20 языков: подписи интерфейса, названия кухонь, типов блюд и аллергенов. Первым идёт русский, вторым английский. Перевод можно поправить прямо в файле, пересобирать сервер не нужно.
- `content/dishes.json` — блюда, перенесённые с WordPress (русский, английский, испанский).
- `content/dishes-extra.json` — добавленные блюда и кухни (русский и английский), названия всех блюд на китайском, японском, корейском, арабском, фарси, хинди, украинском, грузинском, армянском и азербайджанском, а также дополнения к старым блюдам.
- `content/translations/<язык>.json` — полные тексты всех 300 блюд на остальных 19 языках: название, описание, цитата, история, ингредиенты. Заполняют только пустые места: то, что пришло с сайта, не перезаписывается.

- `content/photos.json` — фото блюд со свободной лицензией: путь, автор, лицензия, источник. Заполняется командой `npm run photos:fetch` (см. основной README). Подпись «Фото: автор · лицензия» выводится под фото, полный список — на странице `/photos`.

Если текста на языке страницы нет, показывается английский, затем русский. Такой блок помечается атрибутом `lang`, а на странице блюда появляется пометка «текст пока доступен на английском».

Проверка наполнения (сервер должен быть запущен): `node scripts/check-content.mjs`. Она открывает каждое блюдо на каждом языке и проверяет название, описание, ингредиенты и историю.

## Устройство

```
c/src/main.c    сеть, разбор запросов, маршруты, раздача файлов, редиректы
c/src/pages.c   HTML-шаблоны страниц и JSON-API
c/src/site.c    загрузка блюд, поиск без учёта регистра (ё = е), фильтры
c/src/i18n.c    загрузка языков и подписей из content/i18n.json
c/src/json.c    разбор JSON
c/src/buf.c     строковый буфер и экранирование HTML/JSON/URL
c/static/       style.css и site.js
```

Сервер однопоточный и отвечает с `Connection: close`. Для продакшена его ставят за nginx или Caddy, которые берут на себя HTTPS, сжатие и медленных клиентов.

В этой версии нет ассистента на Claude: для него нужен HTTPS-клиент (libcurl или OpenSSL). Он остаётся в Next.js-версии в корне проекта.
